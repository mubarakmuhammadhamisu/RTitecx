# Route Documentation

## Route
`/pricing`

## Purpose
Redirect-only stub. The public pricing page was intentionally removed —
individual course pricing is shown on each course's detail page and at
checkout instead of a single flat pricing page.

## Type
`page` (Server Component, immediate redirect)

## Access Control
Public.

## Output — Response / Returned State
Always redirects to `/courses`.
